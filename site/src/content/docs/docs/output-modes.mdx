## Typing mode

**Settings → Advanced → Output → Typing Mode** controls how text reaches your app.

### Instant (default)

Abe pastes the whole transcription at once through the clipboard, then puts back whatever was on your clipboard before. It's the fastest option and works in almost every app.

### Typewriter

Abe types the text out word by word using simulated keystrokes. Use it when:

- An app blocks pasting (some remote desktops, terminals, password-protected forms or web apps)
- You'd rather your text didn't pass through the clipboard at all
- You like watching it appear

When typewriter mode is on, a **Typing Speed** slider appears (1,000 to 2,000, default 1,500). Lower it if an app drops characters.

## Transcription style

**Settings → Advanced → Output → Transcription Style** nudges how your speech is written out:

| Style | Result |
|---|---|
| **Formal** | Proper capitalization and punctuation, like written prose |
| **Balanced** (default) | Natural, standard formatting |
| **Relaxed** | Casual, lowercase, minimal punctuation, good for chat |

## Language

**Settings → Transcription → Language** sets the language you speak (English by default). Abe offers 28 languages, plus **Auto-detect** if you switch between languages. Choosing your language explicitly usually gives better accuracy than auto-detect.
